CropNex v6.36.0 — Help, Organisation roles and Trials

Help Centre
- Added a searchable Help & Guides page explaining every main CropNex page and the common workflow.
- Added a short guide to organisation roles, dashboard assignment, employee visibility and job assignment.

Organisation teams
- Added Farmer and Employee organisation roles. Farmer starts with all dashboards and edit access; Employee starts with all dashboards in view-only mode.
- Employee view access is supported by the organisation data-access policies. Employee write access is blocked by the database permission functions, even if an edit option is submitted.
- Farmers can assign Job Cards to active Employee accounts linked to the farm organisation. Assignment is account-based; the existing operator name remains available for field use.
- Added the Trials dashboard to organisation dashboard access.

Trials
- Added trial records by field and season, objectives, dates, crop sale price, control and treatment groups, input rates and prices, operation costs, strip measurements, field-average yield estimates, notes and photos.
- Added treatment comparison and strip/input tables, plus yield and gross-margin comparison graphs.
- Added an Excel workbook export with a summary tab and one worksheet per trial, including treatment costs, strip yields, notes and comparison data. The summary workbook also includes compact in-cell graph bars.

Database migration
- Apply supabase/migrations/202610290001_trials_and_team_roles.sql to add the trial tables, private photo storage policies, account assignments, organisation roles and access rules.
- No live database was changed from this workspace. Apply the migration to the Supabase project before deploying these files.

Deployment
- Full source project supplied as CropNex-Full-Project-V6.36.0.zip.
- After replacing or merging the project, install dependencies and build as usual, then commit and push to deploy through Vercel.
