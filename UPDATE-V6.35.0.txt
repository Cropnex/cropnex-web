CropNex v6.35.0 — Landing page refresh

Landing page
- Expanded the CropNex description to cover maps and fields, seasonal planning, inventory, harvest and transport, finance and reports, farm operations, and AI-assisted tools.
- Added three responsive CropNex workspace previews for farm mapping, seasonal planning and shed inventory. They are clearly marked as illustrative and use sample content.

Deployment
- Upload or merge the full project into the repository.
- Run `npm install` to synchronize package-lock.json with package.json, then `npm run build`.
- Commit and push the updated project to deploy through Vercel.
