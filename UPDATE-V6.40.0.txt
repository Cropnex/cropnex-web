CropNex v6.40.0 — Farming businesses, farms and grouped fields

PURPOSE OF EACH PAGE
Fields & Farms: create farming businesses and their named farms, assign fields
to a saved farm, and edit field names, crop, cultivar, hectares and notes.
Activities & Planning: plan field work and record actual activities and costs.
Reference Lists (formerly Farm Setup): optional reusable cultivar lists,
activity recipes and standard operation rates. Ordinary farm/field management
no longer requires visiting that page. The duplicate farm-creation forms have
been removed from Reference Lists; existing records are retained.
Farm Map: draw/import boundaries, view field labels/layers and open field work.

THE HIERARCHY
Farming business (for example Woranga Agri)
  Farm (for example Preston)
    Fields (for example WO1 and WO2)
  Farm (for example Kalkpan)
    Other fields

These are examples, not automatic changes to your existing farm assignments.
Each saved farm belongs to a farming business. A business can have several
farms, and each farm can have several fields. Fields are displayed inside
their farm's section in the Fields tab, with the business name above the farm
name, field count and total hectares. Empty farms remain visible. Unmatched
older fields are retained in a separate farm-assignment section.

HOW TO USE IT
1. Open Fields & Farms. Your existing Woranga Agri business should be listed.
   Do not create it again. Add farming business is available for a new operation
   that has not been set up yet; no season is needed to create businesses/farms.
2. Click Add farm, select the business, enter the actual farm name and save.
3. Under the appropriate farm, click Edit Field. Select the correct saved farm
   and save the field. It appears under the chosen farm.
4. If the correct farm is missing, use Add a farm here inside the field editor.
   The new farm is immediately selected, while unsaved field details remain.
   Save field details to complete the assignment.
5. Use business and farm filters to focus the register. Choose Fields needing
   farm assignment to find records that cannot be matched to a saved farm.
6. Create NEW field boundaries through Draw / import boundaries. This update
   retains the requirement for mapped boundaries and does not reintroduce
   manual boundaryless field creation.

SAFETY AND ACCESS
- Field assignment updates the existing field record and retains its boundary,
  ID and linked history. No trial, plan or actual record is copied or deleted.
- The field farm dropdown is scoped to the same account and parent business.
  Ambiguous legacy farm names are not automatically assigned to another farm.
- View-only employees see farm groups but not farm creation or field editing.
- The new migration lets organisation members with Fields access read the farm
  hierarchy, and members with Fields editing access create farms for permitted
  clients. A farm's parent business must belong to that same client account.
- Existing Farm Map access continues to work. Master Data remains admin-only.
- Existing plans retain their recorded historical farm-name text; moving a
  field does not rewrite completed operational records. New field data uses
  the selected saved farm.
